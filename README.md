# Генератор рефератов и лабораторных работ по ГОСТ

Этот скрипт автоматически превращает текст, написанный в формате Markdown, 
в готовый документ Microsoft Word (`.docx`), оформленный по ГОСТ 7.32-2017.

**Что умеет скрипт:**
*   Автоматически создавать титульный лист (на основе вашего шаблона).
*   Генерировать оглавление (TOC) с правильными отступами.
*   Форматировать текст (Times New Roman 14, интервал 1.5, отступ 1.25 см).
*   Вставлять сложные математические формулы (LaTeX -> Word OMML).
*   Рисовать Markdown-таблицы с рамками и правильным выравниванием.
*   Вставлять картинки по центру с автонумерацией подписей (Рисунок 1, Рисунок 2...).
*   Оформлять программный код в рамки с серым фоном и моноширинным шрифтом.

---

## 🛠 Шаг 1: Подготовка окружения

Для работы скрипта нужны три вещи: **Python**, **Pandoc** (для формул) и **Python-библиотеки**.

### 1.1. Установка Python
Убедитесь, что у вас установлен Python версии **3.8 или выше**.
*   **Windows / macOS:** Скачайте установщик с официального сайта [python.org](https://www.python.org/downloads/).
*   **Linux (Ubuntu/Debian):** Обычно уже установлен. Если нет:
    ```bash
    sudo apt update
    sudo apt install python3 python3-pip python3-venv
    ```

### 1.2. Установка Pandoc (важно!)
Pandoc — это внешняя программа, которая переводит формулы из LaTeX в формат Word. Без неё формулы не будут работать.
*   **Linux (Ubuntu/Debian):**
    ```bash
    sudo apt install pandoc
    ```
*   **macOS:** (через Homebrew)
    ```bash
    brew install pandoc
    ```
*   **Windows:** Скачайте установщик с [официального сайта](https://pandoc.org/installing.html) и установите (галочку "Add to PATH" оставьте включенной).

*Проверка:* Откройте терминал и напишите `pandoc --version`. Если вы видите номер версии — всё отлично.

## 📦 Шаг 2: Установка зависимостей скрипта

1. Скачайте файлы скрипта в любую удобную папку (например, `Методичка/Скрипты`).
2. Откройте терминал (или командную строку) и перейдите в эту папку:
   ```bash
   cd путь/к/папке/Скрипты
   ```
3. (Рекомендуется) Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   ```
   *Активируйте его:*
   * Linux/macOS: `source .venv/bin/activate`
   * Windows: `.venv\Scripts\activate`
4. Установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

## 📂 Шаг 3: Структура проектов

Скрипт работает по принципу «песочниц». Вы создаете отдельную папку для каждой работы. 

Пример правильной структуры:
```text
Скрипты/  (корневая папка)
│
├── main.py
├── config.py
├── ... (остальные .py файлы)
│
├── Лаба_по_физике/          <-- Папка проекта
│   ├── _Титульник.docx      <-- Шаблон (начинается с _)
│   ├── referat.md           <-- Ваш текст (может быть .txt)
│   └── images/              <-- Папка для картинок
│       └── plot.png
│
└── Курсовая_по_экономике/   <-- Другой проект
    ├── Титульник.docx       <-- (Если шаблон один, _ необязателен)
    ├── text.md
    └── images/
```

### Как создать новый проект?
Просто создайте папку вручную. Положите туда:
1. Один файл `.md` (или `.txt`) с текстом.
2. Один файл `.docx` с титульным листом (желательно назвать его с подчеркиванием в начале, например `_Титульник.docx`, чтобы скрипт сразу его распознал).
3. Папку `images` (если у вас есть картинки).

## ✍️ Шаг 4: Правила написания текста (Markdown)

Скрипт понимает стандартный Markdown, но с некоторыми особенностями.

### Заголовки
*   `# Введение`, `# Заключение`, `# Список литературы` — станут ПРОПИСНЫМИ, встанут по центру и начнутся с новой страницы.
*   `# Глава 1. Название` — заголовок раздела.
*   `## 1.1. Название` — подраздел.

### Формулы
*   **Внутри текста:** `$E = mc^2$` (один доллар).
*   **Отдельной строкой:** `$$ \int_a^b f(x)dx $$` (два доллара). Скрипт сам добавит номер `(1)`.
*   **Длинные формулы:** Если формула не влезает в строку, разбейте её на две части `$$...$$` (вторая должна начинаться со знака `+` или `\quad`).
*   ⚠️ **Запрещено:** Использовать `\( ... \)`, `\begin{aligned}` и `\begin{array}` — они ломают документ в LibreOffice и Word Online.

### Таблицы
Подпись ставится прямо перед таблицей:
```markdown
Таблица 1 — Сравнение методов
| Метод | Оценка |
|:---|:---:|
| A | $O(n)$ |
```

### Картинки
Формат: `![Описание](имя_файла.png)`. Скрипт сам найдет картинку в папке `images`, вставит её по центру и подпишет снизу: *Рисунок 1 — Описание*.

### Код
Оборачивайте код в тройные обратные кавычки с указанием языка (например, ` ```python `). Скрипт сделает для него рамку и шрифт Courier New.

## 🚀 Шаг 5: Генерация документа

Откройте терминал в корневой папке (где лежит `main.py`) и запустите скрипт, указав имя папки проекта:

```bash
python main.py -p "Лаба_по_физике"
```

Если вы назвали папку по-другому, просто измените имя в кавычках.

**Полезные флаги:**
*   `-m файл.md` — если хотите указать конкретный файл текста (игнорируя автопоиск).
*   `-o result.docx` — если хотите сохранить результат под другим именем.
*   `-i images_folder` — если папка с картинками называется иначе.

## ⚠️ Шаг 6: Открытие и обновление документа

1. Откройте сгенерированный файл `referat.docx`.
2. **Оглавление** сначала будет выглядеть как одна строчка: *"Обновите поле: выделите и нажмите F9"*.
3. Нажмите `Ctrl + A` (выделить всё), а затем **`F9`**. Оглавление заполнится всеми главами и номерами страниц.

*Примечание для пользователей LibreOffice / Word Online:*
*   В **Word Online** оглавление может сбивать шрифт на стандартный Calibri (это ограничение браузера). Для идеального вида используйте десктопный Word.
*   В **LibreOffice** сложные формулы иногда отображаются криво из-за особенностей движка LibreOffice Math. Рекомендуется проверять финальный результат в PDF (сохраненном из Word) или использовать Word Online.

## ❓ Частые проблемы (Troubleshooting)

*   **Формулы в Word выглядят как текст `$...$`:** Значит, не установлен Pandoc, или он не добавлен в PATH.
*   **Ошибка `PermissionError`:** Вы пытаетесь запустить скрипт, когда файл `referat.docx` открыт в Word/LibreOffice. Закройте его и попробуйте снова.
*   **Не находит титульник:** Убедитесь, что в папке проекта лежит файл `.docx`. Если их несколько, назовите нужный с подчеркиванием: `_Титульник.docx`.
